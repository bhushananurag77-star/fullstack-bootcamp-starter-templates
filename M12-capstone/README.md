# M12 — Capstone Project & Demo Day

**Week 12 · Mar 22–26, 2027 · Individual Capstone + Demo**

## Goal
Build and present a deployed, portfolio-ready capstone.

## Requirements
- A proposal approved by Friday 19 Mar (see PROPOSAL_TEMPLATE.md)
- A deployed full-stack app demonstrating 12 weeks of learning
- README with architecture, setup and screenshots
- A 5-minute demo for the panel
- Clean code + tests where appropriate

## Deliverables
Approved proposal · deployed app · repo with README · 5-minute demo

## Rubric
- **Scope** — 4: ambitious but delivered · 3: well-scoped · 2: too big/small · 1: unclear
- **Technical depth** — 4: demonstrates breadth + depth · 3: solid · 2: shallow · 1: trivial
- **Completeness** — 4: fully working · 3: mostly · 2: partial · 1: broken
- **Presentation** — 4: crisp demo + honest reflection · 3: clear · 2: unclear · 1: unprepared
- **Portfolio quality** — 4: ready to show employers · 3: close · 2: needs work · 1: not presentable
