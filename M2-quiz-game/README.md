# M2 — Interactive Quiz Game

**Week 2 · Jan 11–17, 2027 · JavaScript Fundamentals**

## Goal
Build a rules-driven quiz game in vanilla JavaScript (console or simple UI).

## Requirements
- At least 5 questions with a tracked score
- Core logic in pure, testable functions (checkAnswer, tallyScore)
- Arrays + objects to model questions and answers
- Loops/conditionals for game flow; functions for reusability
- Clear start/end states and a final score

## Deliverables
Public repo with README · working game · clean commit history

## Stretch goals
Timer · question shuffle · high score in localStorage · difficulty levels

## Rubric (4 / 3 / 2 / 1)
- **Logic & correctness** — 4: flawless, edge cases · 3: correct, minor issues · 2: some bugs · 1: broken
- **Data modelling** — 4: clean arrays/objects · 3: reasonable · 2: messy · 1: hardcoded
- **Code readability** — 4: named functions, DRY · 3: clear, minor dup · 2: confusing · 1: unreadable
- **Edge cases** — 4: invalid input handled · 3: mostly · 2: some gaps · 1: crashes
