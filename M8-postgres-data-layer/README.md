# M8 — Schema Design + Data Layer (PostgreSQL)

**Week 8 · Feb 22–28, 2027 · Databases & SQL**

## Goal
Design a normalised schema and write correct queries against seeded data.

## Requirements
- A schema with at least 3 related tables (e.g., authors, books, reviews)
- Primary keys, foreign keys and indexes
- A seed file with realistic sample data
- At least 10 queries covering CRUD, joins, aggregation and filtering
- Document the schema (ER description)

## Deliverables
schema.sql · seed.sql · queries.sql with commented results · ER description

## Stretch goals
Views, transactions, query performance notes

## Rubric
- **Schema design** — 4: well-normalised, sensible keys/indexes · 3: good · 2: partial · 1: flat
- **Normalisation** — 4: 3NF throughout · 3: mostly · 2: redundant columns · 1: denormalised
- **Query correctness** — 4: all correct & efficient · 3: correct · 2: some wrong · 1: broken
- **Joins/aggregation** — 4: fluent, appropriate · 3: works · 2: awkward · 1: missing
