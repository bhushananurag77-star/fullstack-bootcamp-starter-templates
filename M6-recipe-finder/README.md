# M6 — Recipe Finder SPA

**Week 6 · Feb 8–14, 2027 · React Ecosystem: Routing, State & Data Fetching**

## Goal
A multi-route SPA that fetches real recipe data with solid loading/error handling.

## Requirements
- React Router with at least 3 routes (search, results, detail)
- Data fetching with TanStack Query (query + caching)
- Loading, error and empty states
- Global UI state via context or reducer (e.g., saved recipes)
- URL-driven search (query params)

## Deliverables
Public repo · deployed SPA · documented API usage

## Stretch goals
Pagination · categories · saved list in localStorage

## Rubric
- **Routing** — 4: clean nested routes + params · 3: works · 2: partial · 1: broken
- **Data fetching** — 4: cache/retry/loading/error · 3: solid · 2: gaps · 1: naive fetch
- **Global state** — 4: appropriate context/reducer · 3: reasonable · 2: redundant · 1: chaos
- **SPA UX** — 4: polished · 3: clear · 2: rough · 1: jarring
