# M5 — Movie & Book Library (React)

**Week 5 · Feb 1–7, 2027 · React Essentials**

## Goal
Build a searchable, filterable library UI in React with clean components.

## Requirements
- Scaffold with Vite (React)
- Components: App, SearchBar, ItemList, ItemCard, FilterControls
- State with useState; lift state as needed
- Search + category filter
- Lists with keys; controlled form inputs

## Deliverables
Public repo · deployed demo (Netlify/Vercel) · clean component tree

## Stretch goals
Favourites · detail view · sorting · loading/empty states

## Rubric
- **Component design** — 4: small, single-purpose · 3: reasonable · 2: bloated · 1: mega-component
- **State management** — 4: minimal, lifted correctly · 3: works · 2: redundant · 1: broken
- **Props hygiene** — 4: clear, typed · 3: clear · 2: loose · 1: prop-drilling chaos
- **UX** — 4: polished · 3: clear · 2: rough · 1: unusable
