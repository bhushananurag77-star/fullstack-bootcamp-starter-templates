# M10 — Team Kanban App (Full-Stack)

**Week 10 · Mar 8–14, 2027 · Full-Stack Integration & Team Collaboration**

## Goal
In teams of 4–5, ship a working full-stack kanban app through PRs and code reviews.

## Requirements
- React front-end ↔ Node/Express API ↔ database
- Boards, columns and cards (full CRUD)
- CORS and environment config handled correctly
- GitHub Flow: feature branches → pull requests → code review
- Each member makes commits and reviews others' PRs

## Deliverables
Deployed app · team repo with protected main · recorded demo

## Rubric
- **Integration** — 4: seamless · 3: works · 2: partial · 1: broken
- **Collaboration/Git Flow** — 4: disciplined · 3: followed · 2: loose · 1: chaotic
- **Code review** — 4: thorough · 3: present · 2: superficial · 1: none
- **Individual contribution** — 4: substantial · 3: solid · 2: minimal · 1: unverifiable
