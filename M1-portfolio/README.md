# M1 — Personal Portfolio Landing Page

**Week 1 · Jan 4–10, 2027 · Web Foundations: HTML, CSS & Git**

## Goal
Build a responsive single-page portfolio that introduces you as a developer.

## Requirements
- Semantic HTML5 (header, nav, main, section, footer)
- Responsive layout with Flexbox + CSS Grid (mobile / tablet / desktop)
- At least 3 sections: Hero, Projects, Contact
- Contact form (non-functional OK; validate with HTML attributes)
- CSS custom properties (variables) for the theme
- Git workflow: feature branch → commits → open a pull request

## Deliverables
- Public GitHub repo with README
- Live site on GitHub Pages
- Pull request with a clear description

## Stretch goals
Dark-mode toggle · smooth scroll · subtle animations · Lighthouse ≥ 90

## Rubric (4 Exemplary · 3 Proficient · 2 Developing · 1 Beginning)
- **Semantic & accessible HTML** — 4: valid, semantic, alt/labels/landmarks, a11y ≥ 95 · 3: semantic, minor gaps · 2: some tags, missing a11y · 1: mostly divs
- **Responsive layout** — 4: flawless across breakpoints · 3: responsive, minor overflow · 2: partial · 1: breaks on mobile
- **CSS organisation** — 4: variables + sections + reusable classes · 3: organised, minor dup · 2: works but messy · 1: inline styles
- **Git workflow** — 4: clean branch, descriptive commits, PR · 3: branch+commits+PR, some noise · 2: single commit · 1: no history
- **Presentation & polish** — 4: polished, consistent · 3: clean, minor issues · 2: rough · 1: minimal styling
