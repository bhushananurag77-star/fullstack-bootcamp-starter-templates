# M4 — Weather Dashboard + Unit Tests

**Week 4 · Jan 25–31, 2027 · Advanced JavaScript & Testing**

## Goal
Fetch live weather data and ship meaningful unit tests for your logic.

## Requirements
- Search by city and display current conditions
- Loading and error states for the async fetch
- Break out pure functions (formatTemperature, buildForecast, selectIcon) and test them
- At least 3 passing unit tests (Jest or Vitest)
- Handle API failure gracefully

## Deliverables
Public repo · working dashboard · passing test suite

## Stretch goals
5-day forecast · geolocation · unit conversion · caching

## Rubric
- **Async handling** — 4: robust · 3: works · 2: partial · 1: broken
- **UI states** — 4: loading+error+empty · 3: mostly · 2: gaps · 1: none
- **Test quality** — 4: meaningful, edge cases · 3: solid · 2: superficial · 1: none
- **Code structure** — 4: pure/impure split · 3: reasonable · 2: tangled · 1: sprawl
