# Full-Stack Bootcamp — Starter Templates

Starter templates, project briefs and assessment rubrics for a 12-week full-stack bootcamp (Cohort 2027-A, 25 career changers).

## How to use
Each folder is one module. Open the folder's README for the project brief and 4-point rubric, then build from the starter files.

## Modules
1. **M1-portfolio** — Personal Portfolio Landing Page (HTML/CSS/Git)
2. **M2-quiz-game** — Interactive Quiz Game (JavaScript)
3. **M3-todo-app** — Task Manager To-Do App (DOM + localStorage)
4. **M4-weather-dashboard** — Weather Dashboard + Unit Tests
5. **M5-react-library** — Movie & Book Library (React)
6. **M6-recipe-finder** — Recipe Finder SPA (React Router + TanStack Query)
7. **M7-bookstore-api** — Bookstore REST API (Node/Express)
8. **M8-postgres-data-layer** — Schema Design + Data Layer (PostgreSQL)
9. **M9-auth-api** — Secured API (JWT + roles)
10. **M10-kanban-fullstack** — Team Kanban App (full-stack)
11. **M11-deploy-ci** — Deploy with CI/CD + Docker
12. **M12-capstone** — Capstone + Demo

## Rubric (shared 4-point scale)
- **4 — Exemplary:** exceeds requirements; clean, readable, DRY code; thoughtful edge cases; extra polish.
- **3 — Proficient:** all requirements met and working end-to-end; minor issues only.
- **2 — Developing:** most requirements met but with gaps, bugs, or incomplete features.
- **1 — Beginning:** core functionality missing or not runnable; needs support.
