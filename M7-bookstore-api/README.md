# M7 — Bookstore REST API (Node.js & Express)

**Week 7 · Feb 15–21, 2027 · Backend with Node.js & Express**

## Goal
A full CRUD REST API for books with consistent routes and error handling.

## Requirements
- Express routes following REST conventions (GET / POST / PUT / DELETE)
- Consistent JSON responses and status codes (200 / 201 / 400 / 404)
- Input validation with clear error messages
- Middleware: logging + central error handler
- In-memory or file store, structured for a future DB swap

## Deliverables
Runnable server · Postman/Thunder collection · README with endpoint docs

## Stretch goals
Pagination · search & filter · basic rate limiting

## Rubric
- **REST correctness** — 4: clean resources, verbs, status codes · 3: mostly · 2: inconsistent · 1: broken
- **Route structure** — 4: organised, modular · 3: reasonable · 2: flat/messy · 1: one handler
- **Error handling** — 4: central handler + per-case · 3: handled · 2: partial · 1: crashes
- **Validation** — 4: thorough · 3: basic · 2: partial · 1: none
