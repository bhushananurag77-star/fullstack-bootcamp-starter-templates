# M3 — Task Manager (To-Do) App

**Week 3 · Jan 18–24, 2027 · DOM, Events & Browser APIs**

## Goal
A task manager with add/edit/delete, filters, and persistence.

## Requirements
- Add, complete, edit and delete tasks
- Filter by status (all / active / completed)
- Event delegation for list items
- Persist tasks with localStorage
- Clear visual feedback (empty state, task count)

## Deliverables
Public repo · live demo · commit history

## Stretch goals
Due dates · drag-to-reorder · keyboard shortcuts · dark mode

## Rubric
- **DOM manipulation** — 4: clean, minimal re-render · 3: works · 2: hacky · 1: broken
- **Event handling** — 4: delegation used well · 3: listeners OK · 2: leaks · 1: breaks
- **Persistence** — 4: robust read/write · 3: works · 2: partial · 1: none
- **UX & accessibility** — 4: polished, keyboard-accessible · 3: clear · 2: rough · 1: unusable
